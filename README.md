# TYKHO

Демонстраційний сайт бренду кераміки ручної роботи.

## Публікація на GitHub Pages

1. Завантажте весь вміст цієї папки в корінь репозиторію.
2. Відкрийте **Settings → Pages**.
3. У **Build and deployment** оберіть **Deploy from a branch**.
4. Оберіть гілку **main** та папку **/(root)**, потім натисніть **Save**.

Сайт не потребує встановлення залежностей або збірки.
